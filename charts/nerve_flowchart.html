      • 아래이틀 치아가지 → 아래턱 전체 치아, 치주
      • 턱끝신경 (Mental N.) → 턱끝부위·아랫입술 피부
      • 앞니신경 → 앞니 치아속질

31쌍 — 목(8)·가슴(12)·허리(5)·엉치(5)·꼬리(1)
모든 척수신경의 공통 구성
뒤뿌리(Dorsal root) — 감각 앞뿌리(Ventral root) — 운동 뒤뿌리신경절(DRG) 앞가지(Anterior ramus) 뒤가지(Posterior ramus) → 척주주위근·등 피부 회색교통가지 → 교감신경절 흰교통가지(T1–L2/3) → 교감신경 원심성 되돌이수막신경 → 경질막·뒤세로인대·척추사이원반 뒤부분

목신경 Cervical Nerves
8쌍 (C1: 고리뼈 위, C2–C8: 해당 바위 아래)
목신경얼기 Cervical Plexus C1–C4 앞가지
  • 작은뒤통수신경 (Lesser occipital N.)C2 — 뒤통수부위·귓바퀴 뒤면 피부
  • 큰귓바퀴신경 (Great auricular N.)C2, C3 — 귀밑샘·귓바퀴 피부
  • 목가로신경 (Transverse cervical N.)C2, C3 — 목 앞면 피부
  • 빗장위신경 (Supraclavicular N.)C3, C4 — 내·중·가쪽으로 분기, 빗장위 피부
  • 목신경고리 (Ansa cervicalis)C1–C3
    • 복장목뿔근, 복장방패근, 어깨목뿔근 (하복)
  • 가로막신경 (Phrenic N.)C3, C4, C5 — "C3,4,5 keeps the diaphragm alive"
    • 가로막 (운동+감각)심장막·세로칸 흉막·가로막 복막 감각 포함
팔신경얼기 Brachial Plexus C5–T1 앞가지
Root → Trunk → Division → Cord → Terminal branch

  • 긴가슴신경 (Long thoracic N.)C5, C6, C7 → 앞톱니근 (serratus anterior)
  • 어깨위신경 (Suprascapular N.)C5, C6 → 가시위근, 가시아래근
  • 빗장밑근신경 (Subclavius N.)C5, C6 → 빗장밑근
안쪽다발 (Medial Cord, C8–T1)

  • 안쪽위팔피부신경, 안쪽아래팔피부신경
  • 자신경 (Ulnar N., C7–T1)
    • 손바닥가지 (아래팔 안쪽 피부)
    • 등쪽가지 → 등쪽 손(안쪽 1½ 손가락)
    • 얕은가지 → 새끼두덩근, 4·5번 손가락 촉각
    • 깊은가지 → 뼈사이근 전체(3·4번 공간 포함), 안쪽 2개 벌레근, 엄지모음근
    • 아래팔 내 : 자쪽손목굽힘근, 깊은손가락굽힘근 안쪽 1/2
  • 정중신경 안쪽뿌리 (→ 가쪽두와 합류)
가쪽다발 (Lateral Cord, C5–C7)
  • 가쪽가슴근신경 → 큰가슴근
  • 근육피부신경 (Musculocutaneous N., C5–C7)
    • 근육가지 → 부리위팔근, 위팔두갈래근, 위팔근
    • 가쪽아래팔피부신경 → 아래팔 가쪽 피부
  • 정중신경 가쪽뿌리 (→ 안쪽두와 합류)
정중신경 (Median N., C5–T1) — 가쪽+안쪽다발 합류
  • 아래팔 근육가지 → 원엎침근, 노쪽손목굽힘근, 긴손바닥근, 얕은손가락굽힘근, 깊은손가락굽힘근 가쪽, 긴엄지굽힘근
  • 앞뼈사이신경 (Anterior interosseous N.) → 깊은손가락굽힘근 가쪽 1/2, 긴엄지굽힘근, 네모엎침근
  • 손목굴 통과 후
    • 되돌이가지 (엄지두덩가지) → 짧은엄지벌림근, 짧은엄지굽힘근 얕은갈래, 엄지맞섬근
    • 온바닥쪽손가락신경 (1·2·3번 공간) → 고유바닥쪽손가락신경 → 노쪽 3½ 손가락 감각, 가쪽 2개 벌레근
뒤다발 (Posterior Cord, C5–T1)
  • 위어깨밑신경 → 어깨밑근
  • 가슴등신경 (Thoracodorsal N.) → 넓은등근
  • 아래어깨밑신경 → 어깨밑근 (아래부분), 큰원근
  • 겨드랑신경 (Axillary N., C5–C6)
    • 앞가지 → 어깨세모근 전·중부
    • 뒤가지 → 어깨세모근 뒤부분, 작은원근, 가쪽위팔피부신경
  • 노신경 (Radial N., C5–T1)
    • 위팔세갈래근가지 (위팔 내 분지)
    • 뒤위팔피부신경, 아래가쪽위팔피부신경, 뒤아래팔피부신경
    • 얕은가지 (Superficial br.) → 등쪽 손·노쪽 3½ 손가락 피부
    • 깊은가지 (뒤뼈사이신경)
      • 긴노쪽손목폄근, 짧은노쪽손목폄근 (또는 노신경 직접)
      • 손뒤침근
      • 손가락폄근, 새끼폄근, 자쪽손목폄근, 긴엄지벌림근, 짧은엄지폄근, 긴엄지폄근, 집게폄근
