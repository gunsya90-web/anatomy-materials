# 해부학 학습자료

근육 · 신경 · 동맥 체크리스트(Excel)와 계통도 · 대조표(HTML).
용어는 **대한해부학회 신용어**를 주표기로, 영문은 Terminologia Anatomica를 따릅니다.

> 이전에는 `highway-dispatch` 저장소의 `anatomy-files` 브랜치에 임시로 두었던 자료입니다.
> 2026-09-16에 이 저장소로 옮겼습니다.

## 파일

### `xlsx/` — 학습 체크리스트

| 파일 | 항목 수 | 구성 |
|---|---|---|
| `muscle_checklist.xlsx` | 149개 | 13개 부위 (머리·목·등·가슴·배·어깨·위팔·아래팔·손·골반볼기·넙다리·종아리·발) |
| `nerve_checklist.xlsx` | 55개 | 뇌신경 12쌍 + 5개 신경얼기 |
| `artery_checklist.xlsx` | 62개 | 심장·허파동맥 + 6개 계통 |

각 시트는 `체크` 열에 ☐ / ☑ 드롭다운이 있고, `00_대시보드`가 진행률을 자동 집계합니다(수식 기반).

공통 컬럼 — 근육: 기시·정지·작용·지배신경·혈액공급·촉진·임상 / 신경: 기시·주행·운동·감각·반사·포착부위·임상 / 동맥: 기시·주행·분지·문합·공급부위·동반구조·임상

### `charts/` — 계통도 · 대조표

브라우저로 바로 열면 됩니다(외부 의존성 없음). 라이트·다크 테마를 자동으로 따릅니다.

| 파일 | 내용 |
|---|---|
| `nerve_flowchart.html` | 뇌신경 12쌍 + 척수신경 31쌍의 말단 가지까지 트리 구조 |
| `artery_flowchart.html` | 대동맥에서 말초까지 전체 분지 계통 |
| `muscle_nerve_map.html` | 근육 149개를 지배신경으로 역색인한 계통도 |
| `region_muscle_chart.html` | 부위별 근육 — 관절·운동 방향과 주동/보조 구분 포함 |
| `neurovascular_map.html` | 부위별 근육의 지배신경·영양동맥 + 장기 23개의 자율신경·영양동맥 |
| `term_glossary.html` | 구용어 ↔ 신용어 대조표 724쌍, 양방향 검색 |

여섯 개 모두 맨 위에 **검색창**이 있습니다. 한글·영문 어느 쪽으로도 찾을 수 있고,
계통도에서는 찾은 항목의 **하위 가지가 함께 펼쳐집니다** — `정중신경`을 찾으면 그
아래 앞뼈사이신경·되돌이가지까지 같이 보입니다.

`neurovascular_map.html`은 여기에 더해 신경 이름이나 동맥 이름으로 근육을 거꾸로
걸러 볼 수 있습니다.

### `game/` — 해부 구조물 맞추기 (프로토타입)

`game/anatomy_quiz.html` — 인체 앞모습 SVG(뼈 16 · 근육 12 · 장기 13종)로 즐기는 퀴즈. 브라우저로 바로 열면 됩니다.

| 모드 | 방식 |
|---|---|
| 공부 | 구조물을 누르면 이름 · 영문 · 요점(지배신경 등) 표시 |
| 이름 맞추기 | 노란색으로 표시된 구조물을 4지선다로 맞추기 |
| 위치 찾기 | 제시된 이름의 구조물을 그림에서 직접 누르기 |

뼈 / 근육 / 장기 / 전체 층을 골라 출제하며, 10문항 1라운드 · 연속 정답 · 틀린 것만 다시 풀기를 지원합니다.
공부 모드의 `SVG 저장` 버튼으로 그림을 내려받아 Figma · Inkscape에서 다듬을 수 있습니다.
구조물 데이터는 파일 안의 `S` 배열(id · 신용어 · 영문 · 층 · 설명 · SVG 조각)에 모여 있어 앱으로 옮기기 쉽습니다.

`game/structure_list.csv` — 게임에 넣을 구조물 목록 362개(뼈 · 근육 · 장기 · 신경 · 동맥). 근육 · 신경 · 동맥은 체크리스트 원본, 뼈 · 장기는 별도 작성. `난이도등급` A=전신도에 직접 그림, B=부위 확대도 필요, C=손 · 발 · 머리 · 뇌신경 등 세부 확대도 필요.
`game/samples/shoulder_arm_sample.svg` — 고품질 그림 수준 예시(그라데이션 · 근섬유 · 그림자).

`game/tools/build_parts.py` — 구조물을 **부품 1개 = SVG 1개**(`game/parts/`)로 만들고, 같은 좌표계로 겹쳐 조립한 뷰어(`game/samples/arm_assembly.html`)를 생성합니다. 부품을 누르면 그 구조물만 색이 바뀌고 맨 위로 올라옵니다.

## 용어 기준

구용어는 쓰지 않았습니다. 주요 대응은 다음과 같습니다.

| 구용어 | 신용어 |
|---|---|
| 안면신경 / 설인신경 / 부신경 | 얼굴신경 / 혀인두신경 / 더부신경 |
| 근피신경 / 척골신경 / 요골신경 | 근육피부신경 / 자신경 / 노신경 |
| 좌골신경 / 총비골신경 / 복재신경 | 궁둥신경 / 온종아리신경 / 두렁신경 |
| 쇄골하동맥 / 액와동맥 / 상완동맥 | 빗장밑동맥 / 겨드랑동맥 / 위팔동맥 |
| 관상동맥 / 폐동맥간 / 신동맥 | 심장동맥 / 허파동맥줄기 / 콩팥동맥 |
| 내측 / 외측 | 안쪽 / 가쪽 |

엑셀은 검색 편의를 위해 일부 항목에 `신용어(구용어)` 형태로 구용어를 괄호 병기했고, 흐름도는 신용어와 영문만 사용합니다.

## 자료 신뢰도

대부분은 체크리스트 원본에서 나온 값이지만, 한 곳은 출처가 다릅니다.

| 범위 | 출처 |
|---|---|
| 근육 149개의 지배신경·영양동맥 | 체크리스트 원본 (빈칸 0건) |
| 장기 23개의 영양동맥 | 동맥 체크리스트 `공급부위` 칸에서 역색인 |
| **장기 23개의 자율신경 지배** | **체크리스트에 없던 항목 — 별도 작성, `검증 필요`** |

`neurovascular_map.html` 화면 안에도 같은 내용을 배너로 표시해 두었습니다.
